# Publish the website with GitHub Pages

1. Sign in to GitHub or create an account.
2. Choose **New repository**. Name it `info1005-portfolio` and create it.
3. Open the repository and choose **Add file > Upload files**.
4. Extract `INFO1005_Assessment3_Muzhda_Raoufy_UPLOAD.zip` on your Mac first.
5. Upload the contents inside the extracted folder: `index.html`, `css`, `img`, `pdf`, `docs`, and `README.txt`. Make sure `index.html` is directly in the repository root, not inside another nested folder.
6. Select **Commit changes**.
7. Open **Settings > Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch `main` and folder `/ (root)`, then choose **Save**.
10. Wait for GitHub Pages to publish. Copy the URL shown on the Pages settings screen.
11. Open the URL on a phone and computer to check the layout and links.
12. Paste the live URL into the WSU assessment submission comments if requested.

Do not share your GitHub password with anyone. GitHub Pages hosting must be enabled in your own GitHub account.
